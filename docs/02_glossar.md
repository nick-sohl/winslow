# 2. Fachliches Glossar

| Begriff | Definition |
|---|---|
| **Kurs** | Eine thematisch zusammengehörende Lehrveranstaltung, die von einem Dozierenden geleitet wird und der ein oder mehrere Studierende zugewiesen sind. Ein Kurs enthält eine geordnete Menge von Lektionen. |
| **Lektion** | Eine einzelne Unterrichtseinheit innerhalb eines Kurses. Sie besitzt Metadaten (Lernziele, Termin, Voraussetzungen) und kann mehrere Kursmaterialien enthalten. |
| **Kursmaterial** | Ein hochgeladenes Dokument (PDF, PowerPoint, Skript, Arbeitsblatt), das einer Lektion zugeordnet ist und den Studierenden als Lernressource dient. |
| **Metadaten** | Beschreibende Zusatzinformationen zu einer Lektion oder einem Kurs, insbesondere Lernziele, Termine, Voraussetzungen und thematische Einordnung. |
| **AI-Zusammenfassung** | Eine automatisch durch die AI-Komponente generierte, kompakte Zusammenfassung des Materials einer Lektion. Sie durchläuft einen Prüfungs- und Freigabeprozess durch den Dozierenden. |
| **Lernhilfe** | Automatisch generierte, ergänzende Lerninhalte (z.B. Schlüsselbegriffe, Übungsfragen), die von der AI-Komponente auf Basis des Lektionsmaterials erstellt werden. |
| **AI-Q&A** | Die Funktion der AI-Komponente, kontextbezogene Fragen der Studierenden zu beantworten, wobei ausschliesslich das Material des jeweiligen Kurses als Wissensgrundlage dient. |
| **Kontextindexierung** | Der Prozess, bei dem die AI-Komponente hochgeladene Kursmaterialien analysiert, zerlegt und in einem durchsuchbaren Index ablegt, um kontextbezogene Antworten und Zusammenfassungen zu ermöglichen. |
| **Rollenbasierter Zugriff** | Ein Zugriffssteuerungsmechanismus, bei dem die Berechtigungen eines Benutzers (Einsehen, Bearbeiten, Verwalten) durch seine zugewiesene Rolle (z.B. Studierender, Dozierender, Administrator) bestimmt werden. |
| **Notiz** | Eine persönliche, nur für den erstellenden Studierenden sichtbare Textanmerkung, die einer Lektion oder einem Kursmaterial zugeordnet werden kann. |
| **Dozierender** | Eine Lehrperson, die Kurse erstellt und verwaltet, Materialien hochlädt, Metadaten pflegt und AI-Zusammenfassungen prüft und freigibt. |
| **Studierender** | Eine lernende Person, die eingeschriebenen Kursen zugeordnet ist, Materialien einsieht, die Suchfunktion und AI-Q&A nutzt und persönliche Notizen anlegt. |
| **Volltextsuche** | Die Möglichkeit, über alle indexierten Kursmaterialien hinweg nach Begriffen und Inhalten zu suchen. |
| **Freigabe** | Der Vorgang, bei dem ein Dozierender eine AI-Zusammenfassung nach Prüfung für die Studierenden sichtbar macht. |
| **Sperrung** | Der Vorgang, bei dem ein Dozierender eine AI-Zusammenfassung als ungeeignet markiert und deren Sichtbarkeit für Studierende unterbindet. |
